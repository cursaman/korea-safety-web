# korea-safety-web

한국안전교육 홈페이지의 간단한 Next.js 프런트엔드 데모입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://127.0.0.1:3000 을 엽니다. 빌드 확인은 `npm run build`로 합니다.

## 구현 범위

- 반응형 메인 화면, 교육시간·비용·준비물·연락처 안내
- 히어로 안전교육 사진 3장, 5초 간격 자동 전환과 이전·다음·일시정지 버튼
- 주간 일정 탐색과 날짜 선택
- 신청 입력 화면과 데모 완료 안내
- 자주 묻는 질문, 전화·문자·지도 링크

일정은 평일·토요일 운영 안내를 바탕으로 브라우저에서 생성하는 예시입니다. 휴무·공휴일과 실제 접수 가능 여부는 반영하지 않습니다. 신청 내용은 서버나 로컬 저장소로 전송·저장하지 않습니다. Supabase와 관리자 기능은 연결하지 않았습니다.

히어로 사진은 AI 생성 예시이며 실제 교육장이나 강사의 촬영 기록이 아닙니다. 웹에서는 최적화한 WebP 파일을 사용합니다. 슬라이더 조작 버튼에 포커스하면 자동 전환이 멈추며 재생 버튼으로 다시 시작합니다. 모션 줄이기 설정에서는 자동 재생 없이 시작합니다.

## 후속 작업

실제 일정 API, Supabase 예약 저장, 관리자 인증·권한, 개인정보 동의, 정원 검사 등은 백엔드 작업에서 추가합니다. 운영 전 교육비·시간·주소·연락처를 확인해야 합니다.
